Proyecto base para Hotel Almendro

- Estructura principal:
  - `pages/auth/login.html` — acceso con selección de rol
  - `pages/dashboard/index.html` — dashboard con 3 secciones principales
  - `pages/inventario/inventario.html` — consulta del inventario
  - `pages/inventario/crud.html` — alta, edición y eliminación de productos
  - `pages/operaciones/recepcion.html` y `pages/movimientos/movimientos.html`
  - `pages/mantenimiento/` — mantención, mejoras y remodelación
  - `css/style.css`, `js/main.js`

Abrir `pages/auth/login.html` en el navegador, ingresar un nombre, seleccionar un rol y usar el botón Entrar para ir al dashboard. Los productos, movimientos, recepciones y sesión se guardan en `localStorage`.
